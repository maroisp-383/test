# Application HTML - Règlement prévention incendie 672-2017

Application autonome (un seul fichier `index.html`) en 4 modules:
1. Articles 1 à 27 en tableau 4 colonnes.
2. Dispositions pénales 28 à 34 en tableau 4 colonnes.
3. Simulateur de scénarios (50 scénarios, réponses mélangées, score/100, reset).
4. Section ADMIN (édition JSON, import/export, sauvegarde locale).

## Utilisation
- Ouvrir `index.html` dans un navigateur moderne.
- Aucun serveur requis.
- Pour partager l'application, envoyer simplement le fichier `index.html` (et ce README si désiré).
